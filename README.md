# Millenaire Rewrite

A modern reimplementation of the classic Millenaire mod for Minecraft 1.20.1 using Forge.

## Overview

This project is a faithful recreation of the beloved Millenaire mod, bringing medieval villages and trading systems to modern Minecraft. The mod features multiple cultures including Norman, Byzantine, Japanese, Hindi, and Mayan civilizations.

## Features

### Core Systems
- **Advanced Currency System**: Three-tier currency with copper, silver, and gold deniers
- **Cultural Items**: Authentic items from different civilizations
- **Magic System**: Wands and amulets with special abilities
- **Trading**: Village-based economic system

### Items Implemented
- **Currency**: Denier (copper), Denier d'Argent (silver), Denier d'Or (gold)
- **Magic Items**: Summoning/Negation/Creative wands, various amulets
- **Cultural Foods**: Specialized foods from each civilization
- **Tools & Weapons**: Cultural-specific equipment
- **Armor Sets**: Complete armor sets for each culture

## Development Status

This mod is currently in active development. Core item systems and basic functionality have been implemented.

## Building

1. Clone the repository
2. Run `./gradlew build` to compile the mod
3. Find the built jar in `build/libs/`
