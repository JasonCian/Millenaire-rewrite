## 🎯 华夏文明设计理念

### 核心特色
- **深厚历史底蕴**: 体现中华五千年文明传承
- **传统文化元素**: 融入书法、瓷器、丝绸、茶文化等
- **建筑美学**: 传统中式建筑风格，青砖黛瓦，飞檐斗拱
- **和谐共生**: 强调人与自然的和谐统一

### 文化定位
- **时代背景**: 汉唐盛世时期为主要参考
- **地理环境**: 适合温带和亚热带生物群系
- **社会结构**: 农耕文明，重视教育和手工艺
- **价值观念**: 礼仪之邦，重文轻武，商业繁荣

## 🎨 物品系统设计

### 2.1 货币系统
```java
// 华夏货币层级（由低到高）
COPPER_COIN     // 铜钱 - 基础货币，1个单位
SILVER_TAEL     // 银两 - 中等货币，10铜钱
GOLD_TAEL       // 黄金 - 高级货币，10银两
```

### 2.2 食物系统

#### 主食类
- **米饭** (`COOKED_RICE`) - 南方主食，营养5，饱食度0.6
- **面条** (`NOODLES`) - 北方主食，营养6，饱食度0.7  
- **饺子** (`DUMPLINGS`) - 传统食物，营养8，饱食度0.8

#### 豆制品
- **豆腐** (`TOFU`) - 蛋白质来源，附带轻微生命恢复效果
- **豆浆** (`SOYBEAN_MILK`) - 早餐饮品

#### 饮品
- **茶水** (`TEA`) - 传统饮品，提供夜视效果
- **米酒** (`RICE_WINE`) - 传统酒类，提供临时属性加成

#### 节庆食物
- **月饼** (`MOON_CAKE`) - 中秋节食物，高营养值，提供幸运效果
- **粽子** (`ZONGZI`) - 端午节食物，提供临时保护效果

### 2.3 工具武器系统

#### 青铜时代工具
- **青铜剑** (`BRONZE_SWORD`) - 早期兵器
- **青铜斧** (`BRONZE_AXE`) - 工具兼武器
- **青铜镐** (`BRONZE_PICKAXE`) - 挖掘工具
- **青铜铲** (`BRONZE_SHOVEL`) - 挖掘工具
- **青铜锄** (`BRONZE_HOE`) - 农耕工具

#### 精铁时代工具
- **汉剑** (`HAN_SWORD`) - 经典直剑，高攻击力
- **精铁工具套装** - 高耐久度工具系列

### 2.4 护甲系统

#### 皮甲系列
- 轻甲，适合日常穿戴，低防护

#### 青铜甲系列  
- 中等防护，平衡防御和灵活性

### 2.5 特色装饰物品

## 📝 注意事项

- 严格遵循项目代码规范

- 现代化API使用

- 突出正面文化特色

- 与其他文明保持平衡
