## 主要系统统计

### 1. 方块系统 (Block System)

**位置**: `org.millenaire.common.block`

- **总计**: ~30+ 自定义方块类
- **核心类**: `MillBlocks.java` (注册管理)
- **特殊方块**:
  - 装饰性木材/石材/土质方块
  - 染色砖块和台阶
  - 作物方块（BlockMillCrops）
  - 火炉方块（BlockFirePit）
  - 锁定箱子（BlockLockedChest）
  - 面板方块（BlockPanel）
  - 床铺方块（BlockMillBed）

### 2. 物品系统 (Item System)

**位置**: `org.millenaire.common.item`

- **总计**: ~100+ 自定义物品
- **核心类**: `MillItems.java` (注册管理)
- **特殊物品**:
  - 货币系统 (denier, denieror, denierargent)
  - 文化特定工具和武器
  - 食物和贸易商品
  - 召唤和否定法杖
  - 护身符系统

### 3. 实体系统 (Entity System)

**位置**: `org.millenaire.common.entity`

- **村民实体**: `MillVillager.java` (3057 行，核心类)
- **TileEntity**: 10+ 种特殊方块实体
- **装饰实体**: `EntityWallDecoration.java`
- **敌对实体**: 目标化的 Blaze、Ghast、凋零骷髅

### 4. 文化系统 (Culture System) ⭐ 核心

**位置**: `org.millenaire.common.culture`

- **主类**: `Culture.java` (1290 行)
- **支持文化**:
  - norman (诺曼)
  - byzantine (拜占庭)
  - indian (印度)
  - japanese (日本)
  - mayan (玛雅)
  - inuit (因纽特)
  - seljuk (塞尔柱)
- **关键组件**:
  - 村民类型系统
  - 村庄类型系统
  - 语言系统
  - 建筑风格

### 5. 村庄系统 (Village System) ⭐ 核心

**位置**: `org.millenaire.common.village`

- **主类**: `Building.java` (大型类)
- **建筑规划**: `org.millenaire.common.buildingplan`
- **世界生成**: `WorldGenVillage.java`
- **功能**:
  - 动态建筑建造
  - 村民 AI 和目标系统
  - 贸易系统
  - 军事系统

### 6. GUI 系统 (GUI System)

**位置**: `org.millenaire.client.gui`

- **贸易界面**: `GuiTrade.java`
- **宗教界面**: `GuiPujas.java`
- **文本界面**: `text/` 包
- **配置界面**: 多种配置 GUI

### 7. 网络系统 (Network System)

**位置**: `org.millenaire.common.network`, `org.millenaire.client.network`

- **服务端**: `ServerReceiver.java`, `ServerSender.java`
- **客户端**: `ClientReceiver.java`, `ClientSender.java`
- **通信协议**: `StreamReadWrite.java`

## 主要迁移挑战

### 1. Forge 版本变更 (Critical)

- **1.12.2 → 1.20.1**: 架构重大变化
- **注册系统**: `@ObjectHolder` → 新的注册事件
- **事件系统**: 需要适配新的事件处理

### 2. Minecraft 核心 API 变更

- **方块状态系统**: Properties → BlockStateProperties
- **实体系统**: AI 系统重构
- **渲染系统**: 客户端渲染重构
- **网络系统**: 包结构和处理方式变更

### 3. 复杂度评估

- **高复杂度**: 实体 AI、渲染系统、网络通信
- **中复杂度**: 方块物品注册、GUI 系统
- **低复杂度**: 配置文件、工具类

## 迁移优先级建议

1. **第一阶段**: Forge 集成和基础注册系统
2. **第二阶段**: 方块物品系统迁移
3. **第三阶段**: 基础实体系统
4. **第四阶段**: 文化和村庄核心逻辑
5. **第五阶段**: GUI 和网络系统
6. **第六阶段**: 高级功能（AI、寻路、渲染）

## 总体评估

- **代码量**: ~50,000+ 行 Java 代码
- **预计工作量**: 6-12 个月（全职开发）
- **风险等级**: 高（大量底层 API 变更）
- **成功关键**: 分阶段迁移，保持核心功能逻辑不变
