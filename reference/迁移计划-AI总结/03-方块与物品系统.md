## 2. 方块属性系统迁移

### 原版本 (1.12.2) 属性系统

```java
// 使用IProperty系统
public static final PropertyEnum<EnumType> TYPE =
    PropertyEnum.<EnumType>create("type", EnumType.class);

@Override
protected BlockStateContainer createBlockState() {
    return new BlockStateContainer(this, new IProperty[] {TYPE});
}

@Override
public IBlockState getStateFromMeta(int meta) {
    return this.getDefaultState().withProperty(TYPE, EnumType.byMetadata(meta));
}
```

### 迁移到 1.20.1

```java
// 使用新的属性系统
public static final EnumProperty<EnumType> TYPE =
    EnumProperty.create("type", EnumType.class);

@Override
protected void createBlockStateDefinition(StateDefinition.Builder<Block, BlockState> builder) {
    builder.add(TYPE);
}

// Meta系统已移除，需要重构数据处理
```

## 7. BlockItem 注册迁移

### 原版本 (1.12.2)

```java
public static void registerItemBlocks(RegistryEvent.Register<Item> event) {
    event.getRegistry().registerAll(
        new ItemBlock(WOOD_DECORATION).setRegistryName("wood_deco"),
        new ItemBlockMeta(STONE_DECORATION).setRegistryName("stone_deco")
    );
}
```

### 迁移到 1.20.1

```java
// 在方块注册时同时注册物品
public static final RegistryObject<Block> WOOD_DECORATION =
    BLOCKS.register("wood_deco", () -> new BlockDecorativeWood(...));

public static final RegistryObject<Item> WOOD_DECORATION_ITEM =
    ITEMS.register("wood_deco", () -> new BlockItem(WOOD_DECORATION.get(),
        new Item.Properties()));
```

## 10. 迁移优先级

### 第一优先级 (核心功能)

1. 基础方块注册 (装饰性方块)
2. 基础物品注册 (货币、工具)
3. BlockItem 关联

### 第二优先级 (功能性)

1. TileEntity 方块 (FirePit, LockedChest)
2. 特殊功能物品 (法杖、护身符)
3. 食物系统

### 第三优先级 (高级功能)

1. Mock 方块系统
2. 农业方块系统
3. 复杂交互功能

## 预估工作量

- **基础迁移**: 3-4 周
- **功能测试**: 2 周
- **纹理模型**: 1-2 周
- **优化调试**: 1 周

## 关键风险点

1. **BlockState 系统**: 属性定义变更
2. **TileEntity 系统**: 数据同步方式变更
3. **渲染系统**: 客户端渲染重构
4. **NBT 系统**: 数据序列化方式更新
