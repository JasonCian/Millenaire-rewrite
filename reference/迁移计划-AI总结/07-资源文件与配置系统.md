## 8. 迁移工具开发

### A. 自动转换脚本

#### 语言文件转换器

```python
def convert_lang_to_json(lang_file_path, json_file_path):
    """将.lang文件转换为.json格式"""
    with open(lang_file_path, 'r', encoding='utf-8') as f:
        lines = f.readlines()

    translations = {}
    for line in lines:
        if '=' in line and not line.startswith('#'):
            key, value = line.strip().split('=', 1)
            translations[key] = value

    with open(json_file_path, 'w', encoding='utf-8') as f:
        json.dump(translations, f, indent=2, ensure_ascii=False)
```

#### 纹理路径更新器

```python
def update_texture_paths(model_dir):
    """更新模型文件中的纹理路径"""
    for model_file in glob.glob(f"{model_dir}/**/*.json", recursive=True):
        with open(model_file, 'r') as f:
            data = json.load(f)

        # 更新纹理路径
        if 'textures' in data:
            for key, path in data['textures'].items():
                if path.startswith('millenaire:blocks/'):
                    data['textures'][key] = path.replace('blocks/', 'block/')
                elif path.startswith('millenaire:items/'):
                    data['textures'][key] = path.replace('items/', 'item/')

        with open(model_file, 'w') as f:
            json.dump(data, f, indent=2)
```

## 10. 预估工作量与风险

### 总体时间: 10-12 周 (2.5-3 个月)

#### 工作量分布

- **资源文件处理**: 40% (纹理、模型、音效)
- **配置系统迁移**: 35% (文化、建筑、村民配置)
- **数据包开发**: 15% (配方、战利品、标签)
- **验证测试**: 10% (完整性和兼容性测试)

#### 风险评估

**中风险项**:

- **大量手工处理** - 纹理和配置文件数量庞大
- **文件格式变更** - 语言文件格式转换
- **路径引用更新** - 确保所有引用正确

**低风险项**:

- **纹理文件** - 直接复制，格式兼容
- **音效文件** - 格式基本不变
- **配置逻辑** - 保持向后兼容

### 成功关键因素

1. **自动化工具** - 开发转换和验证脚本
2. **版本控制** - 严格的文件版本管理
3. **增量迁移** - 分批次逐步迁移
4. **充分测试** - 多语言和多文化测试
5. **备份策略** - 完整的原版文件备份
